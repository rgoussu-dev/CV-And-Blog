    The JDK, the JRE & their tools

    # What the JDK ships beyond the compiler — the runtime, and the full catalog of command-line tools grouped by purpose.

    Conceptsaved 2026-08-09 #java#jdk#tooling#jvm

    Overview

    The JDK (Java Development Kit) is the full development distribution: compiler, runtime, and a couple of dozen command-line tools for packaging, inspecting, monitoring and debugging. The JRE (Java Runtime Environment) was the runtime-only subset shipped separately up to Java 8; from Java 9/11 onward Oracle and the OpenJDK vendors stopped distributing standalone JREs — the modular JDK plus jlink lets you cut a custom runtime image containing exactly the modules an application needs, which replaced the one-size-fits-all JRE. In practice today you install a JDK (Temurin, Corretto, Oracle, …) everywhere, and produce trimmed runtimes per application when footprint matters.

    Key points

    • JDK = JRE + tools: historically the JRE was the JDK minus development tools; since the module system (Java 9) the distinction is generated, not shipped — jlink builds runtime images on demand.
    • Install layout: bin/ (all the tools below), lib/ (runtime internals, modules image, src.zip), jmods/ (packaged platform modules consumed by jlink), conf/ (editable configuration: security/java.security, logging, net properties).
    • One java, many roles: the launcher runs classes, jars, modules, and since JEP 330/458 plain source files directly.
    • Inspection is built in: javap disassembles what the compiler generated; jdeps maps class/package/module dependencies and flags JDK-internal API usage.
    • Diagnostics ship with the runtime: jcmd is the umbrella tool; JFR records production-grade profiles with low overhead.
    • Vendors differ in distribution, not tools: every OpenJDK-derived JDK carries essentially this same toolchain (see JVM implementations).

    Details

    Tool catalog

    Purpose Tool What it does
    Compile & run javac Compiles .java sources to bytecode
    Compile & run java Launches classes, jars, modules, source files
    Compile & run jwebserver Minimal static file server for dev use (JEP 408)
    Package & distribute jar Creates/inspects jar archives, manifests, multi-release jars
    Package & distribute jlink Assembles custom runtime images from modules
    Package & distribute jmod Packages .jmod files (native libs, configs) for jlink
    Package & distribute jpackage Builds native installers/app images (msi, dmg, deb…)
    Inspect & document javadoc Generates API documentation from doc comments
    Inspect & document javap Disassembles class files; shows bytecode and constant pool
    Inspect & document jdeps Static dependency analysis; module migration aid
    REPL jshell Interactive read–eval–print loop for exploration
    Monitor & diagnose jcmd Multiplexed diagnostic commands against a live JVM
    Monitor & diagnose jps Lists running JVM processes
    Monitor & diagnose jstat Sampled GC/class/JIT statistics
    Monitor & diagnose jstack Thread dumps; deadlock detection
    Monitor & diagnose jmap Heap dumps and heap histograms
    Monitor & diagnose jconsole GUI monitoring over JMX
    Profile JFR & JMC Flight Recorder events + Mission Control analysis
    Security keytool Manages keystores, certificates, truststores
    Debug jdb Command-line debugger over JDWP

    Build tools drive javac/jar/javadoc for you day to day; the inspection and diagnostic tools are the ones worth knowing by hand.
